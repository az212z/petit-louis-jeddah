# Entrecôte Petit Louis — Jeddah

Independent website design by Ali.

## Run
Node.js 24 LTS. `npm ci`, `npm run dev`. Validate with `npm run typecheck`, `npm run lint`, `npm run build`. Static export: dist/client. GitHub Actions builds with GITHUB_PAGES=true and publishes dist/client/petit-louis-jeddah. No secrets, server, customer-data collection or simulated bookings.

## Content
Menu: data/menu.json; restaurant details: data/restaurant.json; printable menu: public/menu.html. Keep the printable and interactive menu synchronized on updates.

Complete 8-item public HungerStation delivery listing for Jeddah. Dine-in menu and other branches may differ. Snapshot 2026-09-08.

No standalone complete restaurant website found; search and current directories list Instagram/Facebook/delivery only.

Repository inventory checked against 891 repositories on az212z, 8 September 2026. Search indexing cannot guarantee absence in unindexed content.
